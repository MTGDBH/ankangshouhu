# 长寿康使用手册

## 开始使用

在手机或电脑中打开项目管理员给出的地址。使用本人的账号登录，按页面提示选择老人或家属角色。想在电脑上直接进入管家，可打开 `/agent.html`。手机端从底部导航进入管家、趋势、守护或记录入口。如需使用演示功能，请使用管理员提供的隔离演示账号。

## 录入和核对血压等记录

1. 在健康记录中选择血压、血糖、心率等指标，填写读数。按实际测量选择时间和条件。
2. 保存后，在记录页核对来源、录入人和记录时间。本人可进入详情修正或删除。修正后，已关联的复测记录可能需要重新确认。
3. 到趋势页选指标和时间跨度。查看时一起核对测量条件、数据量和可用证据。数据不足或条件不一致时，可回记录页补充。

## 询问智能管家

可以直接问“我最近的血压记录怎么样”“还有哪些复测没有完成”。按提示补充指标、时间范围或其他需要核对的信息。回复下方可查看数据、知识或工具依据。模型暂不可用时，应用会尽量用已核对的数据与本地工具回复。

启用 V2 研究功能后，支持查看数据质量分、缺陷及理由。启用 V3 时序记忆后，可问“比较上月和本月的血压历史趋势”，并展开“查看历史记忆来源”。来源提示有变化时，重新查询并核对健康记录。研究功能由服务端按需开启。

## 改善计划、反馈与复测

1. 在改善计划页建立草案，或者在启用时序功能时请管家按有足够记录的历史时段准备草案。
2. 打开草案，核对做什么、执行频率、记录方法和复测方式。可以编辑后提交，再由本人确认启用。
3. 到计划详情登记执行情况。遇到困难时，填写未完成原因或反馈。已经登记的内容可以按提示修订。
4. 在复测时间窗内录入实际读数，在复测页核对关联。没有足够的前后测量时，系统会提示继续记录。条件一致时可查看描述性的个人前后变化。
5. 在管家中可问“根据上次计划反馈给出血压调整建议”。核对建议后再决定是否修改或另建计划。

## 家属授权与隐私

老人可在照护授权页选择范围并生成一次性授权码，由获授权的家属或医生接受。在协同界面先核对当前选中的老人，再查看数据或代录。代录测量需要专门授权，录入后会标注来源。老人可以从授权列表调整范围或撤回。

在隐私中心可查看访问记录、导出本人数据或确认删除账户。执行删除前请先保存需要保留的资料。在本地演示或评审中宜使用合成数据。审查中发现的授权和云端模型问题见 [最终质量审查](../reports/final-project-quality-review-20261117.md)。

## 安全提示

健康记录、预测和研究建议用于辅助核对和跟踪。如界面提示紧急求助，请按提示联系专业医疗帮助。服药和诊疗方案由医疗专业人员决定。

# V1 验收报告

验收日期为 2026 年 11 月 17 日。实施以原有 Express、SQLite、前端页面和工具编排为基础。开发前确认了账号档案、授权、问卷代填、趋势与基础评分、管家白名单和复测闭环已经存在。本轮补齐测量修正和删除、独立家属代录授权、确认前计划编辑、执行反馈和可溯源预警。现有健康评分及科研预测算法继续沿用。

## 验收矩阵

| 验收项 | 结果或直接依据 |
| --- | --- |
| 测量录入、查询和 SQLite 持久化 | `test_v1_workflows.mjs` 验证七类指标，校验值、单位、测量时间和来源，并用只读 SQLite 连接核对删除和审计。 |
| 趋势及数据完整度 | 同一测试验证 7、30、90、365 天窗口、统计样本和原始记录 ID。核心评分与覆盖率由已有评分测试和接口契约覆盖。 |
| 用户、家庭、权限 | 验证默认授权无代录权限、显式授权、来源和操作人、陌生账号隔离、撤回后一致拒绝。 |
| 真实 LLM 调用 | 服务可达，两组本地凭据均收到 HTTP 401。通过管家 API 验证返回了本地降级结果，状态为 `fallback`，原因码 `LLM_HTTP_401`。真实成功答复待重新验证。 |
| 工具、鉴权与降级 | 新测试覆盖步数问句走真实 SQLite 工具及未获授权的家属，原有白名单、Schema 和紧急转介测试继续使用。 |
| 改善计划与用户反馈 | 验证草案修订、版本冲突、旧凭证失效、本人重新确认、执行未完成与反馈保存。 |
| 复测 | 核对候选测量和真实结果，修正后需要重新确认，删除后撤去关联。 |
| 规则预警 | 验证触发告警时保存规则版本和证据记录 ID，同时不自动创建未经确认的复测任务。 |

## 实际运行记录

| 命令或场景 | 结果 |

| 在 server 目录运行 `npm test` | 通过。包含新增 V1 集成测试、现有 Node 单元与集成、Python 曲线和安全测试、JavaScript 与 Python 语法检查。 |
| `node server/test/e2e/final_acceptance.mjs` | 使用隔离库和本地工具模式通过。原先失败的“我最近走得少吗”断言通过。 |

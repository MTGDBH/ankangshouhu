# V2 研究增强版实验报告

## 实验范围

基于 189 条合成任务开展实验。训练集、验证集、测试集为 63、42、84 条。跨划分未发现相同患者、家庭、模板 ID 或精确重复记录。规范化问句的最大跨划分三字符 Jaccard 相似度为 0.1538，接近重复的筛查阈值为 0.8。

采用本地 Qwen2.5-1.5B-Instruct Q4_K_M，revision `91cad51170dc346986eccefdc2dd33a9da36ead9`，权重校验值 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e`。运行时为 llama.cpp b12466、Vulkan、RTX 5060 Laptop GPU。A–E 每组各跑 42 条，一共 210 条结果。使用提示词 `structured-health-zh.v2.2`。此前还在另一批 42 条合成样本上实跑同样的五组，首轮日志和新版结果均保留。新版与首轮的提示词、样本变体和工具解析有变化，不能将两轮差异单独归因于某次调整。[模型权重来源](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/tree/91cad51170dc346986eccefdc2dd33a9da36ead9)

实验配置、标注定义、公式和复现命令详见 [研究方案](PROTOCOL.md)。统计数据由 [score.mjs](score.mjs) 从逐条输出重算。

## 规则质量与消融

确定性实验覆盖全部 84 条测试样本。D 的缺陷标签微平均 F1 为 40.00%，E 为 93.33%。这两个分数与合成缺陷定义有关。缺失和过期多由基本规则发现，单位、来源、孤立跳变和条件问题需要完整模块。此阶段没有以专业标注支持训练的独立资料，因此未引入学习模型。

质量评估和证据判断在该实现中是串联模块，移除其中任一项得到相同的策略准确率，无法从该样本独立估计两者的贡献。移除质量驱动路由主要改变工具选择，保留了安全策略。按 7、14、30、90 天窗口切片，E 的策略准确率均为 85.71%，工具匹配率在 85.71%–95.24% 之间。候选四、七项时，E 分别匹配 95.24% 和 85.71% 的工具。缺失率大于 0 的 4 条均得到预期补测策略。冲突率大于 0 的 4 条都因用语理解失败走错任务。缺失及冲突切片每种比例只有 1–2 条，结果只能作描述。

## 错误样例与局限

- `test-conflict-2` 将“近 90 天走向”识别成知识咨询，未给已有冲突做质量核对。显式趋势问句的冲突检测已在系统接口测试中通过。
- `test-unspecified-2` 的“上次说的那个数字”没有明确指标。纯研究策略应先追问，但该次执行由于工具不可用而限制回答。
- `test-urgent_colloquial-2` 中的含糊表达未触发紧急求助，属于高风险漏检。高风险门控样本量很小，仍需医疗专业人员复标并扩大自然语言覆盖。
- `test-regular-2` 中模型返回了非法类别 `answer=未发现心率变化`。另有 4 条 E 的实质回复被无效证据引用或数值守卫拦下。提示词与最终证据绑定的稳健性仍影响有效回答率。
- `test-archive-2` 的自然文字提供了操作建议，但模型标为 `ask` 并引用错误来源。当前自动判据可能遗漏此类没有显性数值的语义断言，判断事实性仍需要人审。

真实模型对照使用单个小型量化模型及同源合成样本。结果受模板、知识库规模和输入语言影响。真实人群中的回答准确性和风险分流尚待专业审阅和验证。

## 系统集成

在临时 SQLite 启用 `AGENT_RESEARCH_V2=1` 后，`v2_quality_agent.mjs` 通过。验证了空记录先补测、基于实际入库的合成记录生成摘要和趋势、冲突主动追问、权限不足时不读取个人记录、复测只生成待确认预览，以及原有急症安全路径。趋势工具使用通过质量检查的记录。新研究能力默认关闭，开启后用于受控试运行。

桌面和手机端用 Chrome 实测，均可在缺少血压数据的回复中展开质量分数和具体原因。`server` 下的 `npm test` 已通过完整回归，包括 JavaScript 单元和接口、Python 曲线、GraphRAG、安全和语法检查。
